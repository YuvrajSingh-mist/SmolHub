## A note on a token

An earlier commit in this repository contained a Hugging Face access token.
It was replaced at the time but remained in the history. If that token is
still valid, revoke it at
[huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
The history in the merged repository has been scrubbed.
